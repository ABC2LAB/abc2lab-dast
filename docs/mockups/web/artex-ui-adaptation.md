## 유지한 제품 경계

- 전역 메뉴는 `개요 / 진단 작업` 두 개다. 사용자가 작업을 열면 그 작업의 그래프·판정·재현·범위·보고서를 본다.
- 모델·실행 설정은 새 진단에 통합한다. 별도 설정 메뉴, 동작하지 않는 테마·관리 기능은 추가하지 않는다.
- 확인된 취약점·의심·판단불가·정책상 접근 허용의 의미와 색 구분을 유지한다. 접근 허용은 HTTP 성공이나 취약점 부재를 뜻하지 않는다.
- 전송 불명·차단·미실행 사유를 보존한다. 그래프 재생은 저장된 가상 기록 탐색이며 대상 요청이나 자동 재전송을 만들지 않는다.
- 완료 전에 최종 판정을 만들지 않는다. 중단된 작업은 판정 미발행·관찰 기록 보존으로 표시한다.
- PoC는 placeholder 문서이며 실행하지 않는다. 수정 확인은 과거 작업과 연결된 새 가상 작업이다.
- 대상·LLM·DB·API 연결과 원문 도구 입출력, 실제 에이전트 대화는 추가하지 않는다. API 키는 저장하지 않는다.

## 검토 범위

자산 그래프 구성은 같은 커밋의 `web/src/app/(main)/function/tasks/detail/_tabs/coverage-graph-tab.tsx`에서 확인한 자산 유형 계층·부모별 묶음 노드·엔드포인트 경로 라벨을 참고했다. `assets-tab.tsx`의 메서드·경로 변수·출처 구분도 상세에 반영했다. ABC2LAB에 근거 없는 회사·IP·앱 노드는 추가하지 않았으며, 범위/검사 완료 2상태 대신 전송 불명·미실행·차단 등 기존 상태를 보존한다. 원본의 raw JSON·원문 트래픽 표시와 추가 조회 API는 도입하지 않는다.

검색과 검사 상태 필터는 ABC2LAB 목업의 확장 기능이며 접힌 항목과 상위 계층을 함께 찾는다. 엔드포인트 인벤토리는 현재 작업의 합성 검사 경로에서 만들고, 실제 제품에서는 발견/등록 출처를 보존한 조회 응답으로 교체해야 한다. 서비스의 프로토콜과 포트는 등록 URL에서만 읽고, HTTP 상태·IP·기술 스택을 추정하지 않는다.

Chromium에서 기존 생성→점검→작업 상세→그래프·판정→보고서→수정 확인 흐름과 중단·미확인 상태를 재검사한다. 추가한 검색·필터·빈 결과·방향키·Enter·Esc·입력 이스케이프, 320/390/1024/1440px 화면도 확인한다. 검증은 로컬 합성 자료에 한정하며 실제 서비스 API나 진단 엔진 구현 완료를 의미하지 않는다.
